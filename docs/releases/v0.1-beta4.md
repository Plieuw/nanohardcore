# v0.1-beta4: bootloader (SPL) alleen-lezen uitlezen

Pre-release. Tag `v0.1-beta4` op de merge-commit van deze release (aan te maken door de eigenaar).

## Wat er verandert ten opzichte van v0.1-beta3
- **Fase D1:** HARDCORE kan de bootloaderpartitie `spl` alleen lezen en via USB-MIDI versturen. De pagina `install/spl.html` start dat, controleert elk blok (CRC) en het geheel (SHA-256 tegen de bekende re-nanocore-dump), en biedt `nanocore-spl.bin` aan. Er wordt niets geschreven of gewist.
- **Startsein:** CC 84 met `S` `P` `L`, alleen via USB. Op het scherm staat "SPL LEZEN …%".
- **Installatiepagina:** de introtekst beschrijft nu de HARDCORE-editie (de FX2-tekst is weg), plus een link naar de uitleespagina.
