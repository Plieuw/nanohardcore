NanoCore firmware-backup (alleen lezen)

Deze pagina leest het OS-deel van je NanoCore uit en geeft je een backupbestand. Er wordt niets naar de pedal geschreven. Met die backup kan nanohardcore een patch maken die exact bij jouw firmware past.

  1. Haal koptelefoon en audiokabels eruit en sluit ToneCommand.
  2. Sluit de pedal met USB aan op een computer met desktop Chrome of Edge.
  3. Klik Start, sta MIDI (SysEx) toe en kies daarna Livtra Lupgrader.
  4. Download de backup als het lezen klaar is (~1 minuut).
  5. Haal de USB-kabel eruit en zet de pedal opnieuw aan: hij start normaal op.
